# Beginners-Guide-to-Linux
---
This repository contains the presentation materials for the Beginners Guide to Linux workshop conducted on September 30, 2027.
# Workshop Overview

The session was a collaboration between FOSS @ UCF and IEEE CS @ UCF. The hosts were Richard Hammingh and Ryan Zabatta, IEEE CS workshop chair and FOSS president respecively.

In this workshop we went over what Linux is, why you might want to use Linux, and how to get started using Linux. We helped attendees understand basic terminology and just about everything they would need to know to start using linux.
